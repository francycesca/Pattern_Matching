# Pattern_Matching
IMPLEMENTAZIONE DI ALGORITMI PER IL PROBLEMA DEL PATTERN MATCHING

Il progetto consiste di
- classe "BruteForceAlgorithm" in cui viene implementato l'algoritmo Naive/Brute Force
- classe "Finite Automaton Algorithm" in cui viene implementata la funzione per la creazione della transition function
delta e dell'automa a stati finiti
- classe "Main" per l'esecuzione dei test
- cartella "testi_prova" in cui ho inserito dei file testuali per effettuare i test
- questo file README.txt

Se si esegue il codice nel main, verrà mostrata sul terminale una tabella che riporta il numero di confronti e
il tempo di calcolo impiegato per entrambi gli algoritmi, per ogni test effettuato.
